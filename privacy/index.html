Політика конфіденційності

Інформація про роботу форми й зовнішніх застосунків.

Дані у формі

Ім’я, телефон і деталі, які ви вводите, використовуються у вашому браузері для підготовки тексту. Форма не передає ці поля на сервер. Ви самі вирішуєте, чи копіювати текст і чи надсилати його через SMS.

Зв’язок і хостинг

Під час дзвінка чи надсилання SMS застосовуються умови вашого оператора або застосунку. Вебсайт розміщено на GitHub Pages. Інформацію про роботу хостингу з даними дивіться у заяві GitHub про конфіденційність.
